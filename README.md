## Classificador de Triângulos

Sobre o projeto

Projeto desenvolvido com HTML e JavaScript para praticar lógica de programação e estruturas condicionais.

O programa solicita três valores e utiliza esses dados para classificar o triângulo de acordo com as regras implementadas no código.

Tecnologias utilizadas

* HTML
* JavaScript

Objetivo do projeto

Aplicar conceitos de lógica de programação na análise de valores e na classificação de triângulos.

Conceitos praticados

* Variáveis e entrada de dados.
* Operadores de comparação.
* Estruturas condicionais.
* Organização da lógica de programação.

Aprendizados

Este exercício contribuiu para meu aprendizado inicial de JavaScript e para a compreensão de como utilizar condições para resolver problemas.
